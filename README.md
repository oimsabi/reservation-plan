# Reservation Plan

เว็บภาษาไทยสำหรับรวมข้อมูลและบันทึกการวางแผนเที่ยวอุทยาน

**เปิดเว็บไซต์:** https://oimsabi.github.io/reservation-plan/

## อุทยานในบันทึก

- [Doi Khun Tan](https://oimsabi.github.io/reservation-plan/doi-khun-tan/) — แผนที่บ้านพัก 19 หลัง ตัวเลือกกางเต็นท์ และเครื่องมือเปรียบเทียบค่าใช้จ่าย

ข้อมูลบ้านพักอ้างอิงไฟล์ที่ผู้ใช้จัดเตรียมเมื่อ 14 ตุลาคม 2569 ไม่ใช่ข้อมูลห้องว่างหรือราคาสด โปรดตรวจสอบราคา เงื่อนไขส่วนลด และบริการกับอุทยานหรือระบบจอง DNP ก่อนเดินทาง

## โครงสร้างและการเพิ่มอุทยาน

- `dist/index.html` และ `dist/home.css` เป็นหน้ารวมอุทยาน
- `dist/doi-khun-tan/` เก็บหน้าเว็บ ข้อมูล เครื่องมือคำนวณ รูป และแหล่งอ้างอิงของดอยขุนตาล
- เพิ่มอุทยานโดยสร้างโฟลเดอร์ `dist/<ชื่ออุทยาน>/` พร้อม `index.html` และไฟล์ที่เกี่ยวข้อง แล้วเพิ่มการ์ดลิงก์ในหน้าแรกและปรับจำนวนอุทยาน
- ใช้เส้นทาง relative สำหรับไฟล์ในเว็บ เพิ่มลิงก์กลับ `../` และใส่ `<meta name="robots" content="noindex">` ใน `<head>` ทุกหน้า HTML
- ตรวจไฟล์และแหล่งอ้างอิงก่อน commit ไม่เพิ่มข้อมูลส่วนตัว รหัสแชต ไฟล์ต้นฉบับความละเอียดสูง หรือข้อมูลตั้งค่าของโฮสต์เดิม

เว็บไซต์เป็น static HTML/CSS/JavaScript ไม่ต้องติดตั้ง dependency หรือ build ข้อมูลเนื้อหาแก้ไขผ่านไฟล์ใน repo เครื่องมือขุนตาลจำตัวเลือกไว้เฉพาะเบราว์เซอร์และโดเมนที่ใช้งาน

## ตรวจและเปิดดูในเครื่อง

ใช้ Node.js 24 รัน:

```sh
node checks.cjs
```

หากมี Python ให้เปิด static server จากราก repo:

```sh
python -m http.server 4173 --directory dist
```

จากนั้นเปิด `http://localhost:4173/` ตรวจการเชื่อมหน้ารวม–หน้าอุทยาน การโหลดภาพ หมุดแผนที่ การซูม ตัวกรอง และการเทียบค่าใช้จ่ายทั้งจอมือถือและเดสก์ท็อป

## การเผยแพร่

ตั้งค่า GitHub Pages ให้ใช้ **GitHub Actions** workflow จะรัน checks และเผยแพร่เฉพาะ `dist/` เมื่อ push เข้า `main` หรือสั่ง `workflow_dispatch` การตรวจล้มเหลวจะหยุดการเผยแพร่

repo เริ่มประวัติใหม่จากข้อมูลที่ปรับแล้ว แผนที่เผยแพร่เป็น WebP ขนาด 3,000 × 2,100 พิกเซล คุณภาพ 85 โดยคงสัดส่วน 10:7

ทั้ง repo และเว็บเป็น Public แท็ก `noindex` ใช้ขอให้เสิร์ชเอนจินไม่จัดทำดัชนี ไม่ใช่การจำกัดสิทธิ์เข้าถึง
